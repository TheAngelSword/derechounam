# Documentación histórica

Este directorio conserva material de versiones anteriores para referencia. El subdirectorio `v6.24-original` reproduce los documentos contenidos en el ZIP de origen sin utilizarlos como guía actual. Pueden mencionar el nombre anterior, otro almacenamiento o instrucciones desactualizadas.

Para V7 usa los documentos Markdown de la raíz. El nombre anterior también permanece en comentarios de migraciones que se conservaron idénticas para no modificar el historial de la base de datos.
