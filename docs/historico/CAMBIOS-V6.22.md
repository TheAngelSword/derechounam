# Faculta de Derecho V6.22 — Calendario y resumen de Votaciones

- Votaciones incorpora un calendario mensual de compromisos y actividades pactadas.
- La cabecera muestra actividades activas, actividades con fecha y participaciones.
- Una fecha del calendario permite seleccionar la actividad y abrir directamente su votación.
- Cada votación resume la fecha más seleccionada, el horario más seleccionado y las personas apuntadas.
- El administrador puede fijar una fecha y horario pactados para que prevalezcan sobre el resultado provisional.
- Se agregan campos para lugar/referencia, liga de Google Maps, descripción y comentarios/notas.
- Se conservan los modos Fecha y hora, Me adapto y Varios días.
- No se requiere registro para participar en una votación.
- Requiere la migración `0017_poll_activity_details.sql`.
