# Faculta de Derecho V6.16 — Home privado para usuarios registrados

- El Home ya no muestra el resumen de actividades cuando no hay una sesión iniciada.
- Visitantes ven el mensaje: “Regístrate para tener acceso a todos los recursos del portal.”
- Se agrega el botón “Inicia tu registro”.
- El botón abre directamente el modo “Alta nueva” del acceso.
- El alta inicial solicita únicamente correo y contraseña; el nombre interno se deriva del correo.
- Se mantiene un acceso secundario “Ya tengo cuenta”.
- La información de últimas actividades sólo se carga/renderiza dentro del Home autenticado.
