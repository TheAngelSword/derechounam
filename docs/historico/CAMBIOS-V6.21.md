# Faculta de Derecho V6.21 — apertura real de contenidos en Cátedras y Tareas

## Corrección principal

- En **Cátedras**, seleccionar una fecha con registros ahora muestra un bloque **Registros de este día**.
- Cada registro tiene **Ver contenido** y abre el contenido completo en la misma página.
- Los registros de clase muestran apuntes, referencias, bibliografía y los recursos asociados (audio, archivo/foto y liga complementaria).
- Los recursos protegidos continúan exigiendo una cuenta activa para abrirse.
- Las tareas muestran en Cátedras sus instrucciones completas, método/detalle de entrega, documentación y recurso asociado.
- **Ir a la tarea** ahora lleva a la tarea exacta mediante `#tarea-ID`, no sólo a la página general de Tareas.

## Trabajos y tareas

- Cada tarea tiene ahora **Ver tarea completa / Ocultar tarea**.
- Al abrirla se muestran las instrucciones completas, documentación, método y detalle de entrega y libro/recurso asociado.
- Si se entra desde Cátedras con `#tarea-ID`, la tarea correspondiente se abre y se desplaza automáticamente hasta ella.
- Si la tarea ya es pasada, se abre automáticamente la sección **Tareas pasadas** para poder verla.

## Base de datos

No requiere migraciones nuevas, cambios en Neon, HostGator ni `media.ge01.com`.
